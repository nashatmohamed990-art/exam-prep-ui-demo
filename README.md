# نسخة واجهة متعددة الصفحات

مش موقع UWorld، ومش بنك الأسئلة المدفوع. الأسئلة في `questions.js` أصلية للتجربة.

## الصفحات

- `index.html` الرئيسية
- `products.html` كتالوج المنتجات
- `product.html` صفحة منتج
- `qbank.html` واجهة الأسئلة
- `dashboard.html` لوحة الأداء
- `library.html` مقالات قصيرة
- `educators.html` نموذج المعلمين

عدّل الأسئلة من `questions.js`. كل سؤال فيه stem و choices و answer و why.
